# SlimTrack Sync



Projeto SlimTrack adaptado para sincronizar dados entre computadores usando Firebase.



## Como usar

1. Abra `index.html` em um navegador moderno (Chrome ou Edge recomendado).

2. Digite dados e clique em "Salvar".

3. Clique em "Carregar Histórico" para ver todos os registros.

4. O histórico será sincronizado entre computadores automaticamente.



## Deploy

- Suba o projeto no GitHub.

- Faça deploy no Vercel.

- Acesse pelo link e crie atalho no desktop se desejar.
